# Dashboard-app

The Android phone app for the Dashboard (`android/`): Jetpack Compose in the Huisstijl style, built only via GitHub Actions
(`.github/workflows/android.yml`). Each version downloads as release `telefoon-v<version>`, and the app updates itself from the newest one.

Details, versions and build notes: [android/README.md](android/README.md).

The Windows app was retired on 19-11-2026.
